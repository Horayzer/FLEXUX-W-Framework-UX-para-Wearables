# FLEXUX-W – Framework UX para Wearables

## 📌 Descripción
Este repositorio contiene el proyecto de titulación de Ingeniería en Sistemas de Información enfocado en el diseño de un marco de trabajo para el desarrollo de interfaces en dispositivos wearables.

El proyecto propone **FLEXUX-W**, un framework iterativo orientado a mejorar la experiencia de usuario, accesibilidad y eficiencia en el desarrollo de aplicaciones para dispositivos portables.

## 🎯 Objetivo
Proponer una guía metodológica que facilite el diseño y desarrollo de interfaces centradas en el usuario para dispositivos wearables.

## 🧠 Problemática
El desarrollo de aplicaciones para wearables presenta retos como:
- Limitaciones de pantalla y hardware
- Interacciones rápidas y contextuales
- Accesibilidad y usabilidad
- Falta de metodologías específicas

FLEXUX-W busca abordar estos desafíos mediante un enfoque iterativo y centrado en el usuario.

## 🔄 Framework propuesto: FLEXUX-W
El modelo incluye fases iterativas como:
- Exploración del contexto
- Definición de requerimientos
- Diseño de interfaz
- Evaluación de usabilidad
- Iteración y mejora continua

## ♿ Accesibilidad
El framework incorpora principios basados en:
- WCAG 2.1
- Diseño adaptativo y responsivo
- Buenas prácticas UX/UI

## 📊 Resultado
El proyecto establece una guía estructurada para el desarrollo de interfaces en wearables que mejora la usabilidad y facilita el proceso de diseño.
